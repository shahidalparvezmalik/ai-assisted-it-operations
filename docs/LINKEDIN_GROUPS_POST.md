I have put together a small, runnable demonstration for incident triage using seven fabricated cases. It validates the declared impact and urgency, applies a fixed priority matrix, keeps the evidence note visible, and produces a blank human-review log.

This is a rules-based baseline, not an AI implementation. It does not connect to live services or execute actions. Every case is held for human review.

The code and run instructions are here: https://github.com/shahidalparvezmalik/ai-assisted-it-operations

For teams exploring operational decision support, what information do you require before accepting a suggested incident priority?
